# Microsoft Teams for Linux

 unofficial client: `IsmaelMartinez/teams-for-linux`

- Download the `.deb` build from the repo (releases: https://github.com/IsmaelMartinez/teams-for-linux/releases/)

```bash
wget https://github.com/IsmaelMartinez/teams-for-linux/releases/download/v2.23.0/teams-for-linux_2.23.0_amd64.deb
```

- Install (`apt install ./...` resolves dependencies automatically)

```bash
sudo apt install ./teams-for-linux_2.23.0_amd64.deb
```

- Upgrade later: download the newer `.deb` and run the same install command again
